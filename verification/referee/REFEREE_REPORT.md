## The five minor findings and fixes

### 1. Lemma 20: the affine function l is used as an exterior vector

**Lines 355 and 364; also the concluding use at 374.** P1 permits a *nonconstant affine function* l, whereas the exterior algebra was defined on homogeneous linear forms. Consequently `l wedge m` and using l as a support vector are not literally defined if l has constant term one.

For example, f=a0b0 and h=1+a0 meet the P1 hypotheses and have product zero. The affine function l=1+a0 is a valid affine member of the factor plane, but its exterior vector must be a0. This is a notation defect, not a counterexample to the intended assertion.

**One-line fix:** “In P1, occurrences of l in exterior products and supports mean its homogeneous linear part.” The coordinate change x1=l may remain affine. Products retain their degree bounds under that change, and the exterior statements use its linear part. I checked the P1 argument with that interpretation.

### 2. Lemma 22: the target of the exterior projection is written with the wrong dual

**Line 398.** U was defined at line 98 as the span of four **linear forms**, consistently with `Lambda^2(U)` and the support definition. The map setting a2=b2=0 therefore has target `Lambda(U)`. The displayed target `Lambda(U*)` instead uses the dual of that already-defined space, with no identification specified.

**One-line fix:** Replace `Lambda(U*)` by `Lambda(U)` in the projection sentence. Equivalently, explicitly identify the two using the displayed coordinate basis. The contractions and all subsequent equations use the intended coordinate projection, and S verifies the D1 statement exhaustively. This is a type/notation correction only.

### 3. Proposition 25: make the dimension assumption explicit in its statement

**Lines 445–456.** Its displayed statement does not repeat `dim Q3=3`, but its direct application of Theorem 16 requires `dim Q'=4`. The main theorem's proof has already enlarged Q3 to dimension three at line 529, so the actual application is safe. The proposition is less precise when read as a standalone result with the earlier definition of Q3, which also permits redundant generators.

The distinction is real: take

```
Q3 = span{a0b0, a0b1},
g3 = b0(a1+a0b0) = a1b0+a0b0.
```

This is a semantic nonlinear product that places z1. Its Q'=Q3+<Z1> has dimension **three**, so it does not directly meet Theorem 16's dimension-four hypothesis. This example does not contradict Proposition 25's conclusion.

**One-line fix:** Start the proposition with “Assume dim Q3=3.” If the broader statement is desired, say instead: “Extend Q' by independent rank-two forms to dimension four before applying Theorem 16.” Rank-two extension and monotonicity were already established earlier in the paper. No new obstruction is needed.

### 4. Lemma 28: column permutation alone does not produce [I2 | M]

**Line 480.** The proof says that after a column permutation the given full-row-rank matrix is `[I2 | M]`. A rank-two matrix need not contain the two identity columns. For example,

```
U = [1 1 0 0
     1 0 0 0]
```

has rank two but has no column (0,1). No column permutation gives the asserted identity block. S explicitly detects this counterexample to the normalization sentence and separately verifies the lemma itself for all 210 rank-two matrices and all 1,260 ordered kernel bases.

**One-line fix:** “After a column permutation and invertible row reduction, U=[I2 | M].” Row reduction preserves the kernel, and over F2 its determinant is one, so it preserves all 2x2 minors. The ensuing kernel matrix and complementary-minor comparison are correct.

### 5. Lemma 46: the proof assumes independent factors modulo constants

**Lines 762–764.** The lemma concerns every semantic nonlinear first gate. Such a gate can have factors dependent modulo constants, while the proof subsequently asserts that the normalized affine factor B is nonzero and then counts factor planes.

Example: f=h=P0 is a permitted semantic nonlinear gate and gives g1=P0. Normalization removes the second factor modulo constants and gives B=0. The represented function is zero modulo V1, so the lemma's intended representation still holds; it is the proof's universal nonzero-B assertion that needs qualification. S includes this example.

**One-line fix:** “If the factors are dependent modulo constants, the output lies in V1 and choose B=0; otherwise the factors span a plane and the following argument applies.” The counts 2,016 / 1,920 / 96 remain counts of factor planes, exactly as stated. All cubic branches automatically belong to the independent case.

## Limits and reproducibility

The general six-variable product lemma is verified by its written proof after the minor notation fix. W is exhaustive on four-coordinate pairs, Q is exhaustive on the paper's one/two-direction quadratic prefixes, and C samples one million admissible four-coordinate embeddings in six variables. **C does not sample every possible six-variable quadratic pair**, and neither random run is claimed as a universal proof. The read arguments cover that generality. Likewise the generalized core-cubic pairing and feedback arguments are checked by reading; no exhaustive final-gate search is claimed for those lemmas.

I found no remaining substantive step that I could not verify by reading or by the exact checks described above. This does not claim machine formalization of the prose.
