## Model assumptions (what the computation does and does not prove)

1. Normal form g0 = a0b0 with the linear gates first (Lemma 1 of lambda4_proof.tex, the "normal form" lemma).
2. V3 = {deg ≤ 2, quadratic part in Q3} for linear gates g1, g2 (the analogue of Lemma 2 of lambda4_proof.tex; the brief says "same proof as Lemma 1").
3. λ = 3 exactly: g3 = fh is nonlinear (span{f, h} not inside Aff). The case λ ≥ 4 is the separate human proof (λ = 4) or impossible (λ = 5).
4. Placement of the targets: z0 = g0; z1 ∈ V4 or z1 ∈ g4 + V4; z2 ∈ V4 or z2 ∈ g4 + V4. The pairs (f, h) and {F, H} are taken modulo GL2 and constants (both change fh by an element of V3, respectively FH by an element of V4).
5. Reduction to orbit representatives: a group element φ maps a circuit to a circuit with the same λ and g0 = a0b0, fixes z0 and z1, and changes z2 only by an element of Aff + span{z0} ⊆ V1. This is the argument of Lemma 3 (symmetry; HUMAN PROOF, recorded for λ = 4). Its use for λ = 3 is the same argument but has not been separately reviewed.
6. The level-i test is a necessary condition: D_e and the coefficient extraction are linear, so any real circuit passes it. It was decided exactly (GF(2) linear algebra plus an exhaustive search for a nonzero decomposable 2-vector).

This is a computer-checked exhaustive argument, not a human proof. For Route A (compressed human proofs), the data say what a human lemma must cover: (a) z1-placement, which closes 7911 of 8545 orbits; (b) a first-derivative argument on the last gate for the remaining 634 orbits, where (c, d) ≠ (0, 0) is common, so the λ = 4 proof does not transfer verbatim.
