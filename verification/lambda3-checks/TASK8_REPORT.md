## Part 2 — the human lemma for λ = 3, read off the data

### (a) When z1 cannot be placed

Notation: for a 2-form ω, supp ω is its support, i.e. the row space of its alternating matrix. "minrank" means min over q ∈ Q3 of rank(Z1 + q).

**Candidate Lemma A (z1-placement, λ = 3).** There is a nonlinear g3 = fh (f, h ∈ V3) with z1 ∈ V4 = V3 + ⟨g3⟩ if and only if either Z1 ∈ Q3, or there are q ∈ Q3 and a rank-2 form R ∈ Q3 with rank(Z1 + q) = 2 and supp(Z1 + q) ∩ supp(R) ≠ 0.

No class contradicts Lemma A. The routes "z1 via the last gate" (which would need z2 or z1 + z2 ∈ V4) never occur (n_z2_in_V4 = n_z12_ok = 0 in every class, TASK6_REPORT.md). Sufficiency, by construction: if Z1 + q = l∧r and R = l∧m ∈ Q3 shares the factor l (any nonzero form in the common support can be taken as l), then f = l and h = r + l·m give g3 = fh = lr + lm (using l² = l). Here h is not affine, so g3 is nonlinear, lm ∈ V3, and lr ≡ z1 (mod V3). Necessity is the open half of Lemma A; the data show it holds in every class.
